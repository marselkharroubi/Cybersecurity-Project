Network security basics

Firewalls

A firewall is a security system that monitors and controls incoming and outgoing network traffic based on predefined security rules. It acts as a barrier between a trusted internal network and untrusted external networks, such as the Internet.

How firewalls works:

Blocks unauthorized access.
Allows legitimate network traffic.
Filters traffic based on IP addresses, ports, and protocols.
Protects systems from many network-based attacks.

Virtual Private Networks (VPNs)

A Virtual Private Network creates a secure, encrypted connection between a user's device and a remote network over the Internet. This encrypted connection, called a VPN tunnel, protects data from being intercepted.

Benefits of a VPN:

Encrypts Internet traffic.
Protects sensitive information on public Wi-Fi.
Hides the user's IP address.
Enables secure remote access to private networks.

HTTPS (Hypertext Transfer Protocol Secure)

HTTPS is the secure version of HTTP used for communication between web browsers and websites. It uses SSL/TLS encryption to protect data transmitted over the Internet.

Benefits of HTTPS:

Encrypts data during transmission.
Verifies the identity of websites using digital certificates.
Prevents eavesdropping and data tampering.
Protects sensitive information such as passwords and payment details.

ort Scanning

Port scanning is the process of checking a computer or server for open network ports. Open ports indicate which services are running and may reveal potential security vulnerabilities.

Common uses of port scanning:

Identifying active services.
Detecting unnecessary open ports.
Assessing network security.
Discovering potential attack points.

Common Network Security Tool: Nmap

Nmap (Network Mapper) is one of the most widely used network security tools for network discovery and security auditing.
Nmap can be used to:

Discover devices on a network.
Identify open ports.
Detect running services and their versions.
Identify operating systems.
Perform basic vulnerability assessments.

Symmetric encryption

Symmetric encryption is a type of encryption in which both the sender and the receiver use the same secret key to encrypt and decrypt a message.

It works when a sender encrypts using a secret key which is also shared to the receiver then the receiver uses the same key to decrypt the message that is already been encrypted and stored.

Advantages

Fast making it easier to encrypt large amounts of data and widely used for file encryption.

Disadvantages

The secret key must be shared securely between communicating parties and managing keys becomes more difficult as the number of users increases.

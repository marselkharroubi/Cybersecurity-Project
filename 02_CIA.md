C confidentiality 
confidentiality is when the person have an access to something and no other person can access these information it protected by:

encryption:

encryption is the process of converting readable data into unreadable format common examples is the https which encrypts data between your browser and a website and VPNs which encrypt internet traffic between your device and the VPN server.

Real life example 

On HTTPS

When you log in to your online banking account using HTTPS, your username and password are encrypted while traveling over the internet. Even if someone intercepts the data, they cannot read it without the correct decryption key.

On VPNs 

When you use a VPN on public Wi-Fi (such as at a café or airport), the VPN encrypts your internet traffic, helping keep your personal information private from others on the same network.

Access controls:

Access control is a security method that allows only authorized users to access specific data, systems, or resources while preventing unauthorized users from accessing them.

Real life example 


Unlocking your phone with your fingerprint or Face ID. Only you (or other authorized users) can access the phone, while everyone else is blocked.


A student logs into Xpertbot using their username and password. They can access their history or his wallet, but not other students’ history or wallet for example.


Data classification:


Data classification is the process of sorting data into different categories according to how sensitive or important it is, so the right level of protection can be applied.

Real life example 

A school classifies students’ grades as confidential, while the school calendar is classified as public.

Physical security:

Physical security means using physical barriers and security measures to prevent unauthorized people from accessing or damaging buildings, devices, or information.

Real life example 


A company uses security guards, cameras, and keycard-controlled doors to prevent unauthorized people from entering its office.

I integrity

Integrity is the principle of ensuring that data remains accurate, complete, and unchanged for example by using:

Hashing

Hashing is a security technique that changes data into a unique fixed-size code called a hash. It is used to check that information has not been modified and to help protect sensitive data like passwords.

Real life example

When you create an account on a website, the website stores your password as a hash instead of saving the actual password. When you log in, it hashes your password again and compares it with the stored hash to confirm your identity.

Digital signature:

A digital signature is an electronic verification method that proves who sent a digital message or file and ensures its contents are authentic and unchanged.

Real life example

When a company sends a digitally signed contract, the recipient can verify that it came from the correct person and that the document was not modified after it was signed.

Version control:

Version control is a method used to record and manage different versions of a file or project so changes can be monitored and recovered when necessary.

Real life example

A software development team uses Git to track changes to their code. If a new update causes a problem, they can return to an earlier version of the code.

Checksums:

A checksum is a code created from a file or piece of data to verify that it has not been changed or damaged. By comparing the original checksum with a newly generated one, you can confirm whether the data is still intact.

Real life example

When you download a game or software update, the website may provide a checksum. After the download finishes, your computer can compare the downloaded file’s checksum with the original one. If they match, the file downloaded correctly and wasn’t corrupted or modified.


A availability 

Availability is the principle of ensuring that systems, data, and services are accessible and usable by authorized users whenever they are needed and they are prtotected by: 

Redundancy: 

Redundancy means keeping backup equipment, systems, or copies of data so services can continue working if the main one fails.

Reallife example

A hospital stores patient records on a backup server. If the main server stops working, the backup server takes over so doctors can still access patient information.

DDoS protection:

DDoS protection prevents attackers from overwhelming a website or server with fake traffic, allowing real users to access the service normally.

Real life example

An online shopping website uses DDoS protection during a big sale. If attackers flood the website with fake requests, the protection filters out the malicious traffic so customers can still shop.

Regular backups:

Regular backups mean saving copies of your files on a routine basis to protect them from data loss.

Real life example

A company automatically backs up its employee and customer data every night. If a computer crashes the next day, the files can be restored from the latest backup.

Disaster recovery:

Disaster recovery is a plan for getting systems and data back to normal as quickly as possible after a disaster.

Real life example

After a flood damages a company’s servers, it restores its systems and data from backups and resumes operations within a few hours using its disaster recovery plan.

System monitoring:

System monitoring means regularly watching a system to make sure it is working properly and to quickly identify any issues.

Real-life example:
A bank uses monitoring software to watch its servers 24/7. If a server goes offline or suspicious activity is detected, the IT team is immediately alerted so they can fix the problem.
